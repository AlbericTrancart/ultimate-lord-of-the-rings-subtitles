## How to watch

There are two versions:

- [full subtitles, with English and foreign languages translated](/full-with-english/)
- [foreign languages translated only](/foreign-only/)

These subtitles are made for the Extended versions only. **VLC player with reduced text size is heavily recommended to display subtitles as intended.**

Reducing the text size is useful for the full subtitles version as a lot of text can be displayed at once. For this, you can change it in VLC in the menu `Tools > Preferences > Subtitles > Subtitle Effects > Font Size > Smaller`.

## Contributing

### Adding/changing offsets
If you notice offsets, please submit a new PR adding new files you've updated, but not overwritten using the naming scheme "<file_name> Alternative n.srt" where `n` is the most recent number + 1. This makes it easy for everyone!

### Update Catppuccin colors via script

 - Commit your changes
 - Run `sh ./update_catppuccin.sh` from the repo root on MacOS, Linux, or Windows WSL to automatically update the coloring of Subtitles.
 - Save new changes for catppuccin files as a new commit
